# UNSC Reborn

A Halo total conversion for Starsector 0.98a: two full navies at canonical
scale, the Covenant campaign, ONI's three Sections, the excavation under
Sanctum, and the door that should have stayed shut.

This repository hosts the mod's Version Checker data. The mod itself is
released on the Fractal Softworks forum.

**`UNSC_Reborn.version`** is read by
[Version Checker](https://fractalsoftworks.com/forum/index.php?topic=8181.0)
to announce updates in-game. On each release, the `modVersion` block here is
bumped to match the shipped version.
